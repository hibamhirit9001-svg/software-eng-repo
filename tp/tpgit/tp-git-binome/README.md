# Git TP - Collaborative Repository

## Description

This project is a collaborative Git project created as part of our Git practical work.

The project allows us to practice Git and GitHub commands while working together on the same repository. We created and modified different text files containing examples of fruits, vegetables, spices, and sauces.

We also practiced working with branches, commits, pushes, pulls, merges, and merge conflicts.

## Authors

* Hiba Mhirit
* Salma Mana

## Objectives

The main objectives of this project are:

* Learn how to use Git for version control.
* Create and manage a Git repository.
* Create and modify files.
* Make commits and view the project history.
* Push and pull changes from GitHub.
* Work collaboratively with another student.
* Create and merge branches.
* Generate and resolve merge conflicts.
* Understand how to synchronize a local repository with a remote repository.
* Document the project using Markdown.

## Git Commands Used

Some of the Git commands used during this project are:

```bash
git init
git status
git add
git commit
git push
git pull
git branch
git merge
git log
```

## Project Files

The repository contains several text files used during the practical work:

* `fruits.txt`
* `vegetables.txt`
* `spices.txt`
* `sauces.txt`

## Collaboration

This project was completed collaboratively using Git and GitHub. Each contributor made changes to the repository and synchronized their local work with the remote repository.
